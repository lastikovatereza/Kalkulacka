# Python Kalkulačky

Tento repozitář obsahuje různé typy kalkulaček v Pythonu. Slouží k procvičení základů programování a ukazuje praktické použití konstrukcí jazyka Python, jako jsou `if-else`, `while`, `match-case` a funkce.

## Obsah repozitáře

1. **Jednoducha_kalkulacka.py** – základní aritmetika (sčítání, odčítání, násobení, dělení)  
2. **If_else_kalkulacka.py** – kalkulačka s podmínkami `if-else`  
3. **Match_kalkulacka.py** – kalkulačka využívající `match-case`  
4. **Mocninova_kalkulacka.py** – kalkulačka pro mocniny a exponenty  
5. **While_kalkulacka.py** – kalkulačka s cyklem `while`
